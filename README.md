# Shine Points Game

A game developed in Unreal Engine 5 as a learning project to explore game programming concepts and gameplay systems.

## Features

* AI enemies using Behavior Trees
* Projectile-based combat system (Fireballs)
* Shield mechanics
* Cooldown-based abilities
* HUD built with the MVVM architecture

## Technologies

* Unreal Engine 5.6
* C++
* Behavior Trees
* AI Perception
* MVVM

## Project Goal

The goal of this project was to learn Unreal Engine 5 gameplay programming, AI systems, UI architecture, and character abilities using C++.

## What I Learned

* AI behavior and perception systems
* Ability and cooldown systems
* UI architecture using MVVM
* Character animation setup and configuration
* Gameplay programming in C++
